# Task 01: Install Husky and Initialize

## Status: complete

## Wave

Wave 1 (no dependencies)

## Description

Install Husky v9 and lint-staged as dev dependencies, then initialize the `.husky/` directory structure. This creates the foundation that Tasks 02 and 03 build on.

## Files to Modify

| File | Action | Purpose |
|------|--------|---------|
| `package.json` (root) | Modify | Add `husky` and `lint-staged` to `devDependencies`, add `"prepare": "husky"` script |

## Files Created (by `husky init`)

| File | Purpose |
|------|---------|
| `.husky/pre-commit` | Git pre-commit hook (default placeholder generated by `husky init`) |

## Implementation Steps

### 1. Install dependencies

```bash
pnpm add -D husky lint-staged
```

### 2. Initialize Husky

```bash
pnpx husky init
```

This does two things:
- Adds `"prepare": "husky"` to the `"scripts"` block in root `package.json`
- Creates `.husky/pre-commit` with default content (e.g., `pnpm test` or a comment)

### 3. Clean up the default pre-commit hook

After `husky init`, the `.husky/pre-commit` file will contain a default command. Replace its content with a placeholder comment so Task 02 can overwrite it cleanly:

```bash
echo "# Pre-commit hook — configured by lint-staged" > .husky/pre-commit
```

### 4. Verify the structure

```bash
ls -la .husky/
```

Expected output shows `pre-commit` exists and is executable. Root `package.json` should have `husky` and `lint-staged` in `devDependencies` and `"prepare": "husky"` in `"scripts"`.

## Acceptance Criteria

- `husky` and `lint-staged` appear in `devDependencies` of root `package.json`
- `"prepare": "husky"` exists in root `package.json` scripts
- `.husky/pre-commit` file exists and is executable (`chmod +x`)
- Running `pnpm install` does not produce errors related to Husky setup
- The `.husky/` directory is not ignored by `.gitignore`

## Verification Commands

```bash
# Check deps are installed
pnpm ls husky lint-staged

# Check husky dir exists with executable hook
ls -la .husky/pre-commit

# Simulate the prepare script
pnpm run prepare
```
